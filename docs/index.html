Memory you can audit is memory you can trust.

01

Append-only

Nothing is ever overwritten or deleted—facts are only added. A wrong one stays recoverable, so your memory cannot be silently corrupted.

02

Deterministic retrieval

The same query returns the same result, every time—no model sits in the read path. What surfaces is a fixed formula you can reproduce, not a black box.

03

No server, no cloud

One file on your machine. No account, no vendor, nothing anyone can revoke—back it up by copying a file.

04

Traceable to its source

Every fact links back to the exact raw moment it came from. You can always check where a memory came from, not just what it claims.

05

Just SQLite

Your whole memory is one readable file. Query it in plain SQL—the data your AI sees is the data you can inspect yourself.

06

Model-attributed

Every fact records which model wrote it, and when. Nothing enters your memory anonymously—you can audit exactly what produced each one.
