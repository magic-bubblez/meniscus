M Meniscus
Context layer for AI agents

Every AI agent starts from zero.
Meniscus is the working memory underneath.

A structured, external representation of what you're working on — built from your activity across tools and queryable as a subgraph by any agent. Stop re-explaining yourself to every chat.

How it works

From scattered activity to a queryable subgraph.

Activity flows in from your tools, gets normalized into immutable events, and is structured into threads — clusters of related work that any agent can retrieve as a connected subgraph instead of raw history.

Five stages, two edge types, one shared layer. Activity → Event → Entity → Thread → Subgraph — handed to whichever agent asks.

What you get

Context that lives outside any single tool.

Cross-tool memory

Events captured from ChatGPT, YouTube, GitHub and more — unified into one persistent layer that any agent can read from.

Structured retrieval

Threads are the retrieval unit. Agents fetch a connected subgraph — events, entities, summary — instead of scanning raw history.

Agent-ready by default

One simple /query call returns a grounded answer plus the subgraph that produced it — every response is citation-backed.
